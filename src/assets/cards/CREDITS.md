# 카드 그림 출처와 라이선스

이 폴더의 카드 그림 48장은 Wikimedia Commons의 한국식 화투 세트를 변환한 것입니다.

- **제목:** Hwatu (카드별 파일 이름은 아래 표 참고)
- **작가:** [Spenĉjo](https://commons.wikimedia.org/wiki/User:Spen%C4%89jo)
- **출처:** https://commons.wikimedia.org/wiki/Category:SVG_Hwatu
- **라이선스:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko)

## 변경 사항 (CC BY-SA 4.0의 변경 표시 의무)

- 벡터(SVG) 원본을 가로 224px의 WebP 이미지로 변환(래스터화)했습니다.
- 색을 일부 바꿨습니다: 노랑 `#faea01` → `#eec01a`, 하늘색 `#1ca4da` → `#0a63a8`, 주황 `#f79e33` → `#f0b323`.
- 그 밖의 그림은 고치지 않았습니다. 변환 방법은 `tools/convert-commons-cards.mjs`에 있습니다.

## 이 폴더 이미지의 라이선스

이 폴더의 이미지는 원본과 같은 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko) 조건으로 제공됩니다(동일조건변경허락). 이미지를 사용하거나 다시 배포할 때는 위 작가와 출처를 표시하고, 변경 사항이 있으면 함께 밝히고, 같은 라이선스를 유지해야 합니다.
게임 코드는 이 이미지들과 별개의 저작물입니다.
