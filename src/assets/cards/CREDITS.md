# 카드 이미지 출처

48장 모두 프로젝트 소유자가 나무위키 「화투/패」 문서(https://namu.wiki/w/%ED%99%94%ED%88%AC/%ED%8C%A8)에서 가져온 월별 합성 이미지를 카드 한 장씩 잘라 사용한 것입니다.

- 변경 사항: 합성 이미지에서 카드를 잘라 모서리를 둥글게 처리하고, 가로 240px의 WebP로 변환했습니다.
- 원 출처와 라이선스는 확인되지 않았습니다. 나무위키 문서 본문은 CC BY-NC-SA 2.0 KR이지만, 이미지는 파일별 라이선스를 따릅니다.
- 그림은 Wikimedia Commons의 한국식 화투 세트(Spenĉjo, CC BY-SA 4.0, https://commons.wikimedia.org/wiki/Category:SVG_Hwatu)와 같은 작품으로 보이나 확정된 것은 아닙니다.
- **공개 배포나 상업적 이용 전에 각 이미지의 파일 정보에서 출처와 라이선스를 확인하고, 필요하면 이 문서와 메뉴 화면의 표기를 갱신하세요.**
